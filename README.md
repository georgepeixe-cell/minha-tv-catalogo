# Minha TV — Catálogo de Filmes 0.1

Experimento separado da playlist de TV, com **um curta completo**, Sintel (2010).

## Teste local no VLC
1. Extraia o ZIP.
2. No VLC, abra **Mídia > Abrir arquivo** e selecione `filmes.m3u`.
3. Abra Sintel, espere até 30 segundos e confirme imagem, áudio e reprodução contínua.
4. Caso funcione, publique `filmes.m3u` e `catalogo-filmes.json` em uma pasta `filmes/` do repositório GitHub Pages.

URL após publicação: `https://georgepeixe-cell.github.io/minha-tv-catalogo/filmes/filmes.m3u`

## Estado da fonte
O endereço do vídeo foi encontrado em um índice público de streams, mas **não foi validado em reprodução nesta sessão**. Não é promessa de disponibilidade.
